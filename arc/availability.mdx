| Surface | Status |
| --- | --- |
| ARC models (Anthropic Messages) and Decisions | Beta, open to any Rayline API key, with tier IDs `arc-swift-1.0` and `arc-sage-1.0` |
| ARC on the OpenAI Responses API (`/v1/responses`) | Not yet available |
| Decisions request and response contract | [Documented](/arc/reference/decisions), including multi-turn conversations |
| Responses streaming, tool calls, images, structured output | Confirm availability with the Rayline team before integrating |
| Semantic Router source | [Public fork available](https://github.com/atlasfutures/semantic-router) |
| ARC weights and model-specific self-hosting instructions | Coming soon |
| ARC Swift, Sage, and Decisions token rates | See the [effective rate card](/arc/pricing) and its date |
| ARC Dynamic pricing | Served-model catalog inference price, with 0% ARC commission and no additional routing fee; see [pricing](/arc/pricing#arc-dynamic) |
| Rules Router commission | Confirmed 0% launch policy; coordinate the billing cutover |

See [compatibility](/arc/reference/compatibility) before integrating, and [pricing](/arc/pricing) for the rates and fees of each ARC product.

Production host details, validated SDK examples, and checkpoint release notes for unreleased features will be published when those releases are ready.

This page is an availability record, not a claim that the unreleased features are already enabled.
