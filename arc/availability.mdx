## Check protocol support

Read `GET /v1/arc/prices` on the API origin you will use. For each model, `serving[modelId].available` reports availability and `serving[modelId].protocols` lists `messages`, `chat`, or `responses`. For example:

```bash
curl -fsS https://api.rayline.ai/v1/arc/prices | jq '.serving["arc-sage-1.0"]'
```

Use direct Responses only when the model is available and its protocol list includes `responses`. Production currently advertises `messages` and `chat`. For an environment without Responses support, use Messages or Chat Completions directly, or [Raydock](/raydock/connections#configure-a-cloud-forwarding-gateway) to connect a Responses client to a supported upstream.

Production host details, validated SDK examples, and checkpoint release notes for unreleased features will be published when those releases are ready.

This page is an availability record, not a claim that the unreleased features are already enabled.
