Install [Claude Code](https://code.claude.com) and the [Rayline CLI](/rules-router/cli#install), then sign in with `rayline auth login`.

## With the launcher

```bash
rayline claude --via env -m rayline/arc-sage --auto-compact-window 180000
```

- `-m rayline/arc-sage` sends every request, from the main agent and from subagents, to ARC Sage. Use `-m rayline/arc-swift` for the cheaper Swift tier.
- `--via env` points Claude Code at the hosted router for this session only. Claude Code receives your router key as `ANTHROPIC_AUTH_TOKEN` for the session; the default proxy mode also works and keeps the key out of Claude Code.
- `--auto-compact-window` sets when Claude Code compacts the conversation. From Rayline 0.2.9 the launcher asks the router for this threshold, and the launch fails if the router reports none for the tier; this option supplies it. 180,000 tokens matches the threshold Agent Gateway uses.

Pass Claude Code's own arguments after `--`, for example `rayline claude --via env -m rayline/arc-sage --auto-compact-window 180000 -- --resume`.

## Without the launcher

Load a Rayline key into `RAYLINE_KEY` from your secrets manager; see [API keys](/platform/api-keys). Then:

```bash
export ANTHROPIC_BASE_URL=https://api.rayline.ai
export ANTHROPIC_AUTH_TOKEN="$RAYLINE_KEY"
export ANTHROPIC_MODEL=rayline/arc-sage
export ANTHROPIC_DEFAULT_HAIKU_MODEL=rayline/arc-sage
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=180000
unset ANTHROPIC_API_KEY
claude
```

- Do not append `/v1` to the base URL; Claude Code adds its Messages path.
- `ANTHROPIC_DEFAULT_HAIKU_MODEL` sends Claude Code's background requests, such as titles and summaries, to ARC too. Without it they request a Claude Haiku model.
- Unset `ANTHROPIC_API_KEY` so an Anthropic key in your environment is not sent instead.
- Claude Code prints `unrecognized_model` for the tier ID in debug output and continues; the warning is expected.

## Verify

```bash
claude -p "Reply with exactly the word PONG."
```

The reply is `PONG`. Find the request in [usage](/platform/usage), where it shows the model ARC chose.

To use ARC in Claude Code inside the Claude desktop app, see [Claude Code in Claude Desktop](/arc/coding-tools/claude-desktop); Desktop ignores these environment variables.
