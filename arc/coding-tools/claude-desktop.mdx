<Note>
`rayline claude app` ships in the Rayline release after 0.2.9. Check with `rayline --version`, and update with `rayline update`.
</Note>

<Warning>
**This switches the whole Desktop app away from your Claude subscription.** Claude Desktop reaches a gateway only through its third-party inference mode, which signs the app out of your claude.ai account while it is active. Chat and Cowork are off in that mode; only Code runs, on ARC. [Switch back](#switch-back-to-your-subscription) at any time by signing out and signing in with Anthropic. Your subscription conversations are kept. Claude Code in your terminal keeps its own login and is not affected.
</Warning>

Claude Desktop ignores `ANTHROPIC_BASE_URL`, and it accepts only model IDs that look like Claude models. `rayline claude app` handles both. It runs a small local router for Desktop on `http://127.0.0.1:20831`, where Desktop's model **ARC** (ID `claude-arc-desktop`) is routed to `arc-1.0`. Your Rayline key stays in that router. Desktop stores only a placeholder key.

## Start the router

```bash
rayline auth login
rayline claude app
```

The command starts the router and prints the path of a configuration file for Desktop, `~/.rayline/claude-desktop/claude-desktop-import.json`. This router is separate from the one `rayline claude` and `rayline codex` use, so both can run at once.

To keep the router running after you log out or restart, install it as a login service:

```bash
rayline claude app install-service
```

Without the service, run `rayline claude app` again after a restart.

## Connect Claude Desktop

<Steps>
<Step title="Turn on developer mode">
Open Claude Desktop. From the menu bar, choose **Help → Troubleshooting → Enable Developer Mode**.

{/* screenshot: images/arc/coding-tools/desktop-01-enable-developer-mode.png */}
</Step>
<Step title="Open the third-party inference settings">
Choose **Developer → Configure Third-Party Inference…**.

{/* screenshot: images/arc/coding-tools/desktop-02-developer-menu.png */}
</Step>
<Step title="Import the Rayline configuration">
Choose **Import configuration** and select `~/.rayline/claude-desktop/claude-desktop-import.json`. Check the imported values:

| Setting | Value |
| --- | --- |
| Provider | Gateway |
| Gateway URL | `http://127.0.0.1:20831` |
| API key | `rayline-local-placeholder` |
| Model | `claude-arc-desktop`, shown as **ARC** |
| Model discovery | Off |

{/* screenshot: images/arc/coding-tools/desktop-03-connection.png, desktop-04-models.png */}
</Step>
<Step title="Apply and restart">
Click **Apply Changes**, then **Save & Restart**. On the sign-in screen, continue with the configured gateway instead of signing in with Anthropic.
</Step>
<Step title="Use ARC in Code">
Open **Code** and choose **ARC** in the model picker. Send a short task to check the connection.

{/* screenshot: images/arc/coding-tools/desktop-07-model-picker.png, desktop-08-code-turn.png */}
</Step>
</Steps>

## Check the setup

```bash
rayline claude app status
rayline claude app validate
```

`status` shows whether the router is healthy and how many requests it has served. `validate` compares Desktop's applied configuration with the router and names any setting that differs; it never prints the key. If Desktop reports that it cannot reach the gateway, run `rayline claude app` to start the router.

## Switch back to your subscription

1. In Claude Desktop, open the account menu at the bottom left, which shows **Gateway**, and choose **Sign out**.
2. On the sign-in screen, sign in with your Anthropic account.

{/* screenshot: images/arc/coding-tools/desktop-09-sign-out.png */}

Your claude.ai conversations and settings return. The imported configuration stays in **Developer → Configure Third-Party Inference…**, so you can switch to ARC again by signing out and continuing with the gateway. `rayline claude app off` prints these steps and stops the router.

## Remove it

```bash
rayline claude app uninstall
```

This stops the router, removes the login service and deletes `~/.rayline/claude-desktop`. It does not change Desktop's own settings; delete the gateway configuration in **Developer → Configure Third-Party Inference…** if you no longer want it.

## Limits

- Chat and Cowork are off while Desktop uses the gateway.
- Desktop shows the model as **ARC**. To see which model served a request, use [usage](/platform/usage) or `rayline claude app status`.
- Desktop's effort setting and Claude Code's context-window assumptions are those of a Claude model. ARC chooses the model and effort for each request, and Desktop compacts conversations at its default threshold.
- Anthropic does not support routing Claude Desktop to non-Claude models. A Desktop update can change this behavior.

| Command | Purpose |
| --- | --- |
| `rayline claude app` | Start or reuse the router and print the setup steps |
| `rayline claude app status` | Router health, request totals, and the Desktop check |
| `rayline claude app validate` | Compare Desktop's applied configuration with the router |
| `rayline claude app stop` | Stop the router |
| `rayline claude app install-service` | Start the router at login (macOS) |
| `rayline claude app uninstall-service` | Remove the login service |
| `rayline claude app off` | Print the switch-back steps and stop the router |
| `rayline claude app uninstall` | Remove the service and the router's files |
