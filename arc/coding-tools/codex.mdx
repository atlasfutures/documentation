<Warning>
ARC is not yet available for Codex. Codex supports only the OpenAI Responses API, and ARC does not yet serve Responses requests on `https://api.rayline.ai`: a Responses request for an ARC tier returns `404`. This page will show the ARC setup when Responses support is released.
</Warning>

You can run Codex through Rayline today with [Agent Gateway](/rules-router/quickstart/codex), where your routing rules choose the model. Codex reaches Rayline through a local Responses router, without a proxy certificate.

## Codex CLI

```bash
rayline auth login
rayline codex -- exec "summarize this repo"
```

Rayline starts the local router, points Codex at it for this run, and passes everything after `--` to Codex.

## Codex desktop

```bash
rayline codex app
rayline codex app ~/projects/app
```

`rayline codex app` opens the Codex desktop app on an isolated Codex home, `~/.rayline/codex-app-home`, so your normal Codex settings are untouched. The app runs one instance at a time: if it is already open with other settings, Rayline asks before restarting it.

## Your subscription

Rayline runs Codex desktop on its own Codex home, so your normal Codex login and settings are not changed. To go back, quit the app and open it normally. To use your ChatGPT plan through Rayline, add `--subscription`; see [Codex](/rules-router/quickstart/codex#choose-who-serves-the-requests).
