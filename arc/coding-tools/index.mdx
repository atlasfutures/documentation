ARC chooses a model and reasoning effort for every request your coding agent sends. You connect an agent the same way you connect it to [Agent Gateway](/rules-router), but with the ARC model ID `arc-1.0` instead of `rayline-router`. The agent's tools, files, and sessions stay on your machine; only model requests go to ARC.

| Tool | How to connect | Status |
| --- | --- | --- |
| [Claude Code (CLI)](/arc/coding-tools/claude-code) | `rayline claude --via env -m arc-1.0`, or three environment variables | Tested |
| [Claude Code in Claude Desktop](/arc/coding-tools/claude-desktop) | `rayline claude app`, then import a file in Desktop | Tested; needs the next Rayline release |
| [Codex CLI and Codex desktop](/arc/coding-tools/codex) | `rayline codex` and `rayline codex app` | Not yet available on ARC |
| [opencode, pi, oh-my-pi, Hermes Agent, OpenClaw](/arc/coding-tools/other-agents) | Manual setup with `arc-1.0` | Not yet tested on ARC |

## Before you start

- Install the [Rayline CLI](/rules-router/cli#install) and sign in with `rayline auth login`. The CLI creates a router key for you; see [API keys](/platform/api-keys) to use a workspace key instead.
- ARC requests are billed to your Rayline workspace at the [ARC rates](/arc/pricing). Your Claude or ChatGPT subscription is not used for ARC requests.
- ARC serves Claude Code and other Anthropic Messages clients. It does not yet serve the OpenAI Responses API that Codex requires.

## What changes for the agent

- **The model is ARC's choice.** Each request may be served by a different model, so the model name your agent displays is `arc-1.0` (or **ARC** in Claude Desktop), not the model that answered. Use [usage](/platform/usage) to see which model served a request.
- **Effort settings are advisory.** ARC chooses the reasoning effort with the model. An effort level or thinking budget your agent sends is not guaranteed to be applied.
- **Prompt caching restarts when the model changes.** A switch to another model starts that model's cache from empty; see [caching](/arc/concepts/caching).
- **Anthropic does not support non-Claude models in Claude Code.** Claude Code and Claude Desktop work with ARC through their documented gateway settings, but Anthropic does not support routing them to non-Claude models. A client update can change the behavior, and Anthropic support cannot help with this configuration.
