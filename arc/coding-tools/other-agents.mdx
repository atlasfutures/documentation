The `rayline opencode`, `rayline pi`, `rayline omp`, `rayline hermes`, and `rayline openclaw` launchers always select `rayline-router`, so they route through [Agent Gateway](/rules-router/quickstart/other-agents). They do not accept a model option.

To use ARC with one of these agents, follow its manual setup in the Agent Gateway guide and change the model from `rayline-router` to `rayline/arc-sage`, or to `rayline/arc-swift` for the cheaper Swift tier. Keep the Anthropic Messages API and the base URL `https://api.rayline.ai`:

| Agent | Manual setup |
| --- | --- |
| opencode | [opencode](/rules-router/quickstart/other-agents/opencode) |
| pi | [pi](/rules-router/quickstart/other-agents/pi) |
| oh-my-pi | [oh-my-pi](/rules-router/quickstart/other-agents/omp) |
| Hermes Agent | [Hermes Agent](/rules-router/quickstart/other-agents/hermes) |
| OpenClaw | [OpenClaw](/rules-router/quickstart/other-agents/openclaw) |

Rayline has not yet tested these agents on ARC. Send a short task first and check the request in [usage](/platform/usage). An agent that uses the OpenAI Responses API cannot use ARC yet; see [Codex](/arc/coding-tools/codex).
