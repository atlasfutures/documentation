## Choose the right product

Use **ARC** when you want adaptive model selection. Use [Agent Gateway](/rules-router) to connect agents and subagents to models with routing policies you control. Use [Workshop](/workshop) when you want to build directly in an app.

Start with [your first preview request](/arc/quickstart). You do not need to install the Rayline desktop app to explore ARC.
