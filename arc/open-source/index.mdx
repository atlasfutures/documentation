## The routing foundation

vLLM Semantic Router provides a programmable layer for selecting model paths across inference infrastructure. Our fork is where you can inspect the source we build on. It is not a claim that every upstream feature is available through Rayline's hosted APIs.

The fork currently uses `rayline_main` as its default branch. Use a pinned commit or release when reproducing a deployment; a moving branch is not a stable deployment contract.

## ARC model releases

Check the fork's license and notices before redistributing it, and check each model's license separately. A routing runtime's license does not grant rights to every model it can call. We credit the upstream vLLM Semantic Router contributors; Rayline did not originate that project.
