Current rates for ARC Swift, ARC Sage, the Routes API and the Decisions API are on [rayline.ai/pricing](https://rayline.ai/pricing). This page explains how each is billed.

## ARC Swift and Sage

Each tier has a fixed rate card for each data mode, in US dollars per million tokens, with four legs: input, cache read, cache write, and output. Every request is billed at its tier's card, whichever model serves it. Swift and Sage Contributor have their own cards. See [Swift and Sage](/arc/models).

## ARC Dynamic

Pay the served model’s catalog inference price. ARC adds **0% commission**, with no additional routing fee. This applies to `arc-1.0`, `arc-contributor-1.0` and `arc-zdr-1.0`. See [configure ARC routing](/arc/dynamic).

## Routes API

The Routes API bills the tokens ARC reads to choose a route, once per request, however many results it returns. Its rate card has an encoded-input rate and a cache-read rate, with no charge for cache writes or output.

The Routes API does not yet reuse a cached prefix between requests. So every token a route reads is billed at the encoded-input rate, and `usage.cache_read_tokens` is 0. Once the Routes API reuses a conversation's prefix, the cache-read rate will apply and `cache_read_tokens` will report those tokens.

Your provider bills the inference you run. Prices you send in `routing.prices` change which model ARC selects, not this fee. See [Routes API](/arc/routes).

## Decisions API

The Decisions API is priced the same as the Routes API, in each data mode: <code>{decisionsModel}</code> (Standard), <code>{decisionsContributorModel}</code> (Contributor) and <code>{decisionsZdrModel}</code> (zero data retention). It bills the input tokens ARC reads to answer a request: the state plus every question, as reported in `usage.input_tokens`. There is no output charge. Tokens reported as `usage.input_tokens_details.cached_tokens` are billed at the same input rate. Refused requests are not billed. See [Decisions API pricing and privacy](/arc/decisions-api/pricing-and-privacy).

## How requests are billed

Each request records the rate it was billed at; see [funding and billing](/platform/billing) and [usage](/platform/usage). Workshop has its own [plans and credits](/workshop/pricing/plans).
