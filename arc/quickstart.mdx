Any Rayline API key can use ARC. You need no separate access request.

## Choose a tier

| Tier | Model ID | Use it for |
| --- | --- | --- |
| ARC Swift | `arc-swift-1.0` | Fast workhorse for everyday coding and agent tasks |
| ARC Sage | `arc-sage-1.0` | Harder tasks where quality matters more than cost |

Both tiers choose a model and reasoning effort for every request. Tier IDs may change before launch.

<Steps>
<Step title="Get a key">
Create a key in **API Keys** on the [Rayline Platform](https://platform.rayline.ai/keys), or run `raydock auth login` with the [Raydock CLI](/raydock/cli#install). See [API keys](/platform/api-keys). Keep the key in `RAYLINE_API_KEY`, outside your source code:

```bash
export RAYLINE_API_KEY="<your Rayline API key>"
```
</Step>
<Step title="Add funds">
Add funds to the workspace on the [Rayline Platform](https://platform.rayline.ai) before your first request. Requests and decisions are paid from the workspace's prepaid balance; without one, they return `402` (`billing_error`). See [funding and billing](/platform/billing).
</Step>
<Step title="Send a request">

```bash
curl --fail-with-body https://api.rayline.ai/v1/messages \
  -H "x-api-key: $RAYLINE_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -H "x-conversation-id: quickstart-1" \
  -d '{"model":"arc-swift-1.0","max_tokens":512,"messages":[{"role":"user","content":"Summarize the purpose of a regression test."}]}'
```

This is the [Anthropic Messages](https://docs.anthropic.com/en/api/messages) API: ARC chooses the model, runs the turn, and returns the answer. Send the same `x-conversation-id` on later turns so ARC decides them in context. ARC also answers on OpenAI Chat Completions (`/v1/chat/completions`). Direct OpenAI Responses (`/v1/responses`) requires an environment that [advertises Responses support](/arc/availability#check-protocol-support).
</Step>
<Step title="Try a decision">

```bash
curl --fail-with-body https://api.rayline.ai/v1/routes \
  -H "Authorization: Bearer $RAYLINE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "x-conversation-id: quickstart-2" \
  -d '{"model":"arc-swift-1.0","messages":[{"role":"user","content":"Review a database migration for data-loss risks."}]}'
```

The response names the `model` and `thinking` configuration to run in your own stack. See [Decisions](/arc/decisions) and the [Decisions reference](/arc/reference/decisions).
</Step>
<Step title="Inspect the request">
Find the request in [usage](/platform/usage), with the model ARC chose and the tokens it used.
</Step>
</Steps>

To use ARC from an agent harness, see [use in your tools](/tools).
