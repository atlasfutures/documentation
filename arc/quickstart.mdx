<Note>
ARC is in private preview. Contact [hello@rayline.ai](mailto:hello@rayline.ai) to request early access.
</Note>

Creating an API key or funding a workspace does not enable ARC. Wait for the Rayline team to confirm access before sending requests. The Responses example illustrates the proposed interface; the Decisions example uses the documented [Decisions API](/arc/reference/decisions).

<Steps>
<Step title="Get access and a key">
Request early access from the Rayline team. Once your access is confirmed, follow the team's instructions to create a key for the assigned environment and workspace. See [API keys](/platform/api-keys). A gateway key is not a substitute for ARC access.
</Step>
<Step title="Copy the preview base URL">
For Responses, use the ARC API base URL provided by the Rayline team. Decisions uses `https://api.rayline.ai`. Keep the URL and key in environment variables, outside your source code.
</Step>
<Step title="Send a Responses request">

```bash
# Set ARC_BASE_URL and RAYLINE_API_KEY to your preview URL and key first.
curl --fail-with-body "$ARC_BASE_URL/v1/responses" \
  -H "Authorization: Bearer $RAYLINE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input":"Summarize the purpose of a regression test."}'
```

API access is limited during private preview. Confirm your access and the supported request and response fields with the Rayline team before integrating.
</Step>
<Step title="Try a decision">

```bash
curl --fail-with-body https://api.rayline.ai/v1/routes \
  -H "Authorization: Bearer $RAYLINE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "x-conversation-id: quickstart-1" \
  -d '{"messages":[{"role":"user","content":"Review a database migration for data-loss risks."}]}'
```

The response names the `model` and `thinking` configuration to run in your own stack. Send the next turn with the same `x-conversation-id` so ARC decides it in context. See the [Decisions reference](/arc/reference/decisions).
</Step>
<Step title="Inspect the request">
Once access is enabled, follow the Rayline team's guidance for inspecting requests in your workspace. See the [Responses reference](/arc/reference/responses) or [Decisions reference](/arc/reference/decisions) for availability.
</Step>
</Steps>
