Any Rayline API key can use ARC. Request ARC with a tier model ID, `arc-swift-1.0` or `arc-sage-1.0`, on the Anthropic Messages API (`POST https://api.rayline.ai/v1/messages`). Routes API support is listed below.

Do not assume support for streaming, tool calls, structured output, image or audio inputs, or provider SDK compatibility based on an endpoint's protocol name. Confirm these capabilities before building an integration.

<span id="decisions" />

## Routes API

| Capability | Support |
| --- | --- |
| Request format | Anthropic Messages, OpenAI Chat Completions, and OpenAI Responses bodies |
| Format selection | Read from the body; see [request formats](/arc/reference/routes#request) |
| Multi-turn conversations | Yes, with `x-conversation-id` |
| Streaming | No; each route is one JSON response |
| Tools in the request | Accepted; check the response `warnings` for whether they influenced the route |
