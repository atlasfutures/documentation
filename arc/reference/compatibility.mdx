Any Rayline API key can use ARC. Request ARC with an ARC model ID, `arc-swift-1.0`, `arc-sage-1.0` or `arc-1.0`, on the Anthropic Messages API (`POST https://api.rayline.ai/v1/messages`). Decisions support is listed below.

Do not assume support for streaming, tool calls, structured output, image or audio inputs, or provider SDK compatibility based on an endpoint's protocol name. Confirm these capabilities before building an integration.

## Decisions

| Capability | Support |
| --- | --- |
| Request format | Anthropic Messages, OpenAI Chat Completions, and OpenAI Responses bodies |
| Format selection | Read from the body; see [request formats](/arc/reference/decisions#request) |
| Multi-turn conversations | Not yet; each lookup is decided from the conversation in the request body. Send `x-conversation-id` on every turn |
| Routing policy presets (`routing.policy`) | Accepted; production admits only `arc-policy.package-default.v1` until the hybrid launch |
| Execution envelope (`routing.execution`) | Accepted; served on the development environment, production after the hybrid launch |
| Per-candidate predictions (`routing.response_fields`) | Served where `GET /v1/arc/prices` reports `serving.decisions.predictions: true` |
| Streaming | No; each decision is one JSON response |
| Tools in the request | Accepted; check the response `warnings` for whether they influenced the decision |

Follow the [guide for your tool](/tools) for its provider settings, ARC model IDs, and connection options. The [client compatibility guide](/tools/connections) explains how the Rayline Platform and Raydock connect to different clients.
