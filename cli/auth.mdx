## rayline auth login

Authenticate with Rayline by signing in through the browser.

```bash
rayline auth login
```

Opens `platform.rayline.ai/cli-auth` in your default browser. After signing in, credentials are saved to `~/.config/rayline/credentials.json`.

### Options

| Flag | Description |
|---|---|
| `--env <name>` | Environment to authenticate against (`prod` or `dev`). Default: `prod` |

### Example

```bash
rayline auth login              # login to production
rayline auth login --env dev    # login to dev environment
```

## rayline auth logout

Remove stored credentials.

```bash
rayline auth logout
```

### Options

| Flag | Description |
|---|---|
| `--env <name>` | Environment to log out of. Default: `prod` |

## rayline auth token

Print the current auth token to stdout. Useful for scripting or setting environment variables.

```bash
rayline auth token
```

### Example

```bash
# Use the token in an environment variable
export ANTHROPIC_API_KEY=$(rayline auth token)
```

If not logged in, prints an error and exits with code 1.

### Options

| Flag | Description |
|---|---|
| `--env <name>` | Environment to get token for. Default: `prod` |

## Credential storage

Credentials are stored in plain JSON at `~/.config/rayline/credentials.json`. The file contains your auth token — treat it like any other secret. The file is readable only by your user (mode `0600`).

To revoke access, run `rayline auth logout` or delete the credentials file directly.
