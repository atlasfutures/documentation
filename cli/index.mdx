The `rayline` CLI is Rayline's command-line tool. It manages authentication, launches Claude Code with routing pre-configured, controls the local router daemon, and manages the Rayline app.

## Install

```bash
curl -fsSL https://get.rayline.ai/install.sh | bash
```

This installs the `rayline` binary to your PATH. Verify with:

```bash
rayline --version
```

## Update

```bash
rayline update
```

Downloads and installs the latest version. Use `--check` to see if an update is available without installing:

```bash
rayline update --check
```

## Command overview

| Command | Purpose |
|---|---|
| [`rayline auth`](/cli/auth) | Authentication — login, logout, token management |
| [`rayline claude`](/cli/claude) | Launch Claude Code with Rayline routing |
| [`rayline router`](/cli/router) | Manage the local router daemon |
| [`rayline menubar`](/cli/menubar) | Manage the Rayline app |
| `rayline status` | Show current auth, router, and environment state |
| `rayline update` | Update to the latest CLI version |
| `rayline --version` | Print version |

## Global options

### `--env`

Switch between environments:

```bash
rayline --env dev auth login    # authenticate against dev environment
rayline --env prod claude       # use production (default)
```

Most users never need this — `prod` is the default.

## Configuration

The CLI stores configuration in `~/.config/rayline/`:

| File | Contents |
|---|---|
| `credentials.json` | Auth tokens (written by `rayline auth login`) |
| `claude-daemon-launches.json` | Tracks Rayline app auto-launch state |

The router daemon stores its state in `~/.rayline/rld/`:

| File | Contents |
|---|---|
| `rl-rld.pid` | Daemon process ID |
| `rl-rld.log` | Daemon logs |
| `rl-rld.meta` | Daemon metadata (model, ports, mode) |

## Environment variables

| Variable | Effect |
|---|---|
| `RAYLINE_MENUBAR_OPT_OUT=1` | Disable Rayline app auto-install on `rayline claude` |
| `RAYLINE_HOOK_OPT_OUT=1` | Disable telemetry hooks |
| `RAYLINE_ROUTER_HOOKS_ACTIVE` | Set by hooks when active (internal) |
