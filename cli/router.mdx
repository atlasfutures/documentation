The `rayline router` commands control the local router daemon (`rld`), which runs on-device model inference. You rarely need these directly — `rayline claude --local` starts the daemon for you. Reach for `rayline router` when you want to manage on-device inference on its own.

## rayline router start

Start the local router daemon with on-device model inference.

```bash
rayline router start
```

On first run, downloads the default model (~20GB) and starts all local services. Subsequent starts are near-instant.

### Options

| Flag | Default | Description |
|---|---|---|
| `--model-repo <repo>` | `unsloth/Qwen3.6-35B-A3B-GGUF` | Hugging Face repository for the model |
| `--model-file <file>` | `Qwen3.6-35B-A3B-UD-Q4_K_M.gguf` | Specific GGUF file within the repository |
| `--adapter-port <port>` | `20808` | Port for the local model adapter |
| `--injector-port <port>` | `20809` | Port for the request injector |
| `--router-url <url>` | `https://api.rayline.ai` | Cloud router URL |
| `--env <name>` | `prod` | Environment |

### Examples

```bash
# Start with defaults
rayline router start

# Start with a custom model
rayline router start --model-repo "your-org/model-GGUF" --model-file "model-Q4_K_M.gguf"

# Custom ports
rayline router start --adapter-port 20818 --injector-port 20819
```

### What starts

| Service | Default port | Purpose |
|---|---|---|
| llama-server | 8081 | Local inference engine |
| Adapter | 20808 | Proxies to llama-server, reports usage |
| Injector | 20809 | Intercepts requests, redirects eligible ones locally |

## rayline router stop

Stop all local router services.

```bash
rayline router stop
```

Terminates the daemon, adapter, and injector. Cloud routing through Rayline continues to work normally — only local routing is affected.

## rayline router status

Show the current state of the local router.

```bash
rayline router status
```

Output includes:
- Daemon PID and running state
- Loaded model
- Port assignments for each service
- Health check status for each endpoint

### Example output

```
rld: pid 12345, running
  model: Qwen3.6-35B-A3B-UD-Q4_K_M.gguf (unsloth/Qwen3.6-35B-A3B-GGUF)
  adapter   :20808 ✓
  injector  :20809 ✓
  llama     :8081  ✓
  router_url: https://api.rayline.ai
  log: /Users/you/.rayline/rld/rl-rld.log
```

## rayline router logs

View recent daemon logs.

```bash
rayline router logs            # last 50 lines
rayline router logs -n 200     # last 200 lines
```

Useful for diagnosing startup failures, model loading issues, or request errors.

## Health checks

`rayline router start` waits for all services to become healthy before returning. The default health timeout is 240 seconds (longer on first run when downloading the model — up to 3600 seconds).

If a service fails to start, check `rayline router logs` for the error.
