The Rayline app gives you a glanceable overview of your routing activity — and a one-click way to launch Claude Code — without opening the full dashboard. It lives in your macOS menu bar and shows live data.

## Installation

### Automatic (recommended)

If you use the `rayline` CLI, the Rayline app is installed automatically on first run of `rayline claude` on macOS (Apple Silicon).

### Manual

```bash
rayline menubar install
```

This downloads the latest Rayline build and installs it to `/Applications`.

### Starting and stopping

```bash
rayline menubar start    # launch the Rayline app
rayline menubar stop     # quit the Rayline app
```

Or just launch Rayline from `/Applications` like any Mac app.

## What it shows

Click the Rayline icon in your menu bar to open the popover:

### Launch Claude Code

The primary action (⌘↩) — one click starts a routed Claude Code session in a new Terminal window, running `rayline claude` for you. Below it, **Copy launch command** (⌘C) copies the command to paste anywhere, and **Install command line tools** symlinks `rayline` and `rld` into `/usr/local/bin` so they're on your PATH.

### Cost savings

A summary of your routing savings at the top of the popover — the amount saved over Today / 7 days / 30 days, and how much cheaper that is versus running everything on a frontier model. Same counterfactual calculation as the dashboard, updated in near-real-time.

### Routing controls

- **Main model** — pin the main agent to a specific model, or leave it on **Dynamic** to let the router decide.
- **Activity** — recent routed requests with model, tokens, cache, latency, cost, and savings.
- **Routing config** — switch between ML and rules-based routing and toggle on-device routing.

### Account

The footer shows your signed-in email and a quit button, and **Open dashboard** jumps to the full router dashboard in your browser.

## Authentication

The Rayline app uses the same credentials as the `rayline` CLI. If you've run `rayline auth login`, it picks up those credentials automatically from `~/.config/rayline/credentials.json`.

If you see "Not logged in" in the Rayline app, click the **Login** button in the popover (it runs `rayline auth login` for you), or run it yourself:

```bash
rayline auth login
```

## Auto-start

On macOS (Apple Silicon), `rayline claude` installs and launches the Rayline app for you on first run — there's no separate autostart command to configure.

## Opting out

If you don't want the Rayline app to auto-install when running `rayline claude`:

```bash
export RAYLINE_MENUBAR_OPT_OUT=1
```

Add this to your `~/.zshrc` to make it permanent.

## Requirements

- macOS 13+ (Ventura or later)
- Apple Silicon (M1 or later) for auto-install; Intel Macs can use manual install if a build is available
