Coding agents like Claude Code delegate heavily — code review, frontend, debugging, test generation. Each subagent call goes to one of Anthropic's models: Opus, Sonnet, or Haiku.

The problem? For many of these tasks, Sonnet and Haiku are outperformed by open-source alternatives that cost a fraction of the price. You're paying a [frontier tax](https://rayline.ai/research/the-frontier-tax) on work that doesn't need it.

Rayline routes each subagent call to the model most likely to succeed, at the lowest cost. Frontier where it matters. Open-source models everywhere else. On-device when it fits.

## Start in 2 minutes

Install the `rl` CLI and launch Claude Code through Rayline — one command handles sign-in, your routing key, and configuration:

```bash
curl -fsSL https://get.rayline.ai/install.sh | bash
rl claude
```

That's it. Your main agent stays on the model you chose. Subagent calls route through Rayline automatically.

On macOS you can skip the terminal entirely — the **Rayline menubar app** (installed on first run) launches Claude Code with one click. Prefer to wire the raw Anthropic environment variables yourself? See [Advanced setup](/quickstart/claude-code#advanced-manual-environment-variables).

## How much does it save?

Rayline charges model pass-through pricing with a **7.5% routing fee**. No platform fees, no monthly minimums.

The savings come from routing. When a Sonnet subagent call (output priced at `$15` per million tokens) gets routed to DeepSeek V4 Pro (`$3.48`/MTok) or GLM-5.1 (`$3.20`/MTok) — models that match or beat Sonnet on code tasks — you save 75–80% on that call, even after the markup.

Typical users see **50–80% cost reduction** on subagent spend, depending on workload mix.

## Why open-source models?

The open-source ecosystem has caught up — and in many cases surpassed — distilled frontier models on coding tasks. DeepSeek V4 Pro, Kimi K2.6, and Qwen 3.7 Max all score higher than Claude Sonnet 4.6 and Claude Haiku 4.5 on the [LM Arena leaderboard](https://lmarena.ai), at a fraction of the cost.

Rayline's research on this is published at [The Frontier Tax](https://rayline.ai/research/the-frontier-tax).
