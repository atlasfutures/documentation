---
title: "API keys"
description: "Use a key for the right Rayline workspace and environment."
---

Create a key in **API Keys** on the [Rayline platform](https://platform.rayline.ai/keys). Keep it on the server or in your secrets manager, not in browser-delivered code.

1. Sign in and select the workspace you intend to use.
2. Create a key and copy it while it is shown.
3. Supply it as an environment variable to your integration.
4. Revoke it in the platform if it is exposed; create a replacement and update your callers.

Rayline keys use the `rlk-` prefix. A workspace key's access is tied to its workspace; use a separate key for each integration where practical.

## Private preview

ARC preview access requires a key and base URL from the development environment. Production Agent Gateway access does not establish that ARC preview access is enabled. Copy the ARC example from your development platform instead of substituting the Agent Gateway endpoint.

## Security

Never commit a key, paste it into a public issue, or log authorization headers. Logging out of a CLI is not equivalent to revoking a leaked key. When sharing a failed request, include the request ID and sanitized error, not the secret.

Workshop's app account and credits are separate from this API-key setup. See [Workshop account help](/workshop/account-deletion) and [plans](/workshop/pricing/plans).
