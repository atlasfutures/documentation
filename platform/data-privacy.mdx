Each organization has a data setting, which its owners change under **Organization** > **Data use** in the platform:

| Setting | What it means |
| --- | --- |
| Standard (default) | Requests aren't stored by Rayline and aren't used for training, except requests to a [Contributor model](#contributor-models), which owners can turn off with **Allow Contributor models**. Only models whose providers keep request data for 30 days or less, and never train on it, serve the request. |
| Contributor | Requests may be used to improve ARC routing. Every model is available. |
| Zero data retention | Requests are served only by providers that store nothing. |

On the Rayline API, an ARC request follows its model ID rather than this setting, as described below.

## ARC model IDs choose the data mode

On the Rayline API, the ARC model ID you send decides the data mode of an ARC request, not the organization's setting:

| Model IDs | Data mode |
| --- | --- |
| `arc-swift-1.0`, `arc-sage-1.0`, `arc-1.0` | Standard |
| `arc-swift-contributor-1.0`, `arc-sage-contributor-1.0`, `arc-contributor-1.0` | Contributor |
| `arc-swift-zdr-1.0`, `arc-sage-zdr-1.0`, `arc-zdr-1.0` | Zero data retention |

An organization on zero data retention can use only the zero data retention IDs. Any other ARC ID is refused with a `403` `zdr_model_required` error, which names the ID to use, before any model is called. Requests to other models follow the organization's setting.

| Surface | Used to improve ARC | Exploration |
| --- | --- | --- |
| ARC Swift, ARC Sage, ARC Dynamic (hosted inference) | Only with a Contributor model ID | About 5% of requests with a Contributor model ID; 0 otherwise |
| Routes API | Never | None by default; only the routing temperature you set |
| Raydock and self-hosted routing | Not covered by this hosted policy | Set by your own configuration |

A local connector that forwards to hosted inference follows the hosted rows.

When Rayline cannot confirm your organization's data setting for a request, it handles the request as zero data retention: no exploration, no training use, and only the zero data retention ARC IDs are served.

## Contributor models

A request to `arc-swift-contributor-1.0`, `arc-sage-contributor-1.0` or `arc-contributor-1.0` runs in Contributor, whether your organization's setting is Standard or Contributor and whatever your own privacy setting.

- Organizations on zero data retention can't use Contributor models: the request is refused with `zdr_model_required`.
- Owners can turn Contributor models off for the organization with **Allow Contributor models** under **Organization** > **Data use**. A request to a Contributor model is then refused with a `403` `contributor_models_off` error before it reaches any model.
- Your usage lists these requests under the Contributor model you named.

A model that Standard or zero data retention doesn't allow is refused with a `privacy_mode_model_unavailable` error rather than swapped for another model. Choose another model, or switch the organization to Contributor.

The organization-level data setting is rolling out. Until it is available for your organization, contact [hello@rayline.ai](mailto:hello@rayline.ai) to confirm how your requests are handled. Workshop data is governed by [Workshop's terms](/workshop).
