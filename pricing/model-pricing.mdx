## How to read this table

- **Input**: cost per 1M input tokens (the prompt you send)
- **Output**: cost per 1M output tokens (the model's response)
- **Cache Read**: discounted rate when tokens are served from the provider's prompt cache
- **Cache Write**: rate for writing tokens into prompt cache (Anthropic only)
- All prices include the 7.5% Rayline routing fee
- Provider base prices are public — multiply any Rayline price by `÷ 1.075` to get the base

## Cost estimation

A typical Claude Code session with subagent delegation:

| Scenario | Approx. cost without routing | Approx. cost with Rayline |
|---|---|---|
| Simple feature (10 subagent calls) | `$0.50`–`$2.00` | `$0.10`–`$0.50` |
| Complex feature (50 subagent calls) | `$2.00`–`$8.00` | `$0.40`–`$2.00` |
| Large refactor (100+ subagent calls) | `$5.00`–`$20.00` | `$1.00`–`$5.00` |

Actual costs depend on token volumes, model mix, and how effectively routing matches tasks to cheaper models. Most users see 50–80% savings on subagent spend.
