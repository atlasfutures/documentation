A Rayline API key (`rlk-...`) authenticates your requests. If you launch with `rayline claude`, one is provisioned for you automatically — you only need to create a key by hand for the [manual env-var setup](/quickstart/claude-code#advanced-manual-environment-variables). There are two ways to get one.

## Option 1: Platform dashboard (web)

1. Go to [platform.rayline.ai/signup](https://platform.rayline.ai/signup)
2. Create an account (email or Google sign-in)
3. Complete the onboarding — add your name and optionally fund your account
4. Navigate to **API Keys** in the sidebar
5. Click **Create Key** — your key is shown once, so copy it immediately

Your key looks like: `rlk-k9f2a7b3...`

## Option 2: CLI

If you've installed the `rayline` CLI:

```bash
rayline auth login
```

This opens a browser authentication flow. After signing in, your credentials are stored locally at `~/.config/rayline/credentials.json`. `rayline claude` uses these automatically — you don't need to manage a key by hand.

To print your routing key (`rlk-…`) for use in environment variables:

```bash
rayline claude key
```

## Adding funds

Rayline is pay-as-you-go. You route requests and pay for the tokens consumed, plus a 7.5% routing fee.

During onboarding (or anytime in the dashboard), you can:

1. **Add a one-time top-up** — `$5`, `$10`, `$25`, `$50`, or a custom amount
2. **Enable auto-topup** — automatically recharge when your balance drops below a threshold

<Tip>
Starting with `$10` gives you plenty of runway to evaluate. A typical Claude Code session with heavy subagent delegation costs `$1`–`$5` depending on task complexity.
</Tip>

## Key security

- API keys are prefixed `rlk-` so they're easily identifiable in your shell history and config files.
- Keys authenticate all requests through Rayline — treat them like any other API key.
- You can revoke and rotate keys from the [API Keys page](https://platform.rayline.ai/keys) at any time.
- Never commit keys to version control. Use environment variables or a secrets manager.

## Environment setup

Once you have your key, export it in your shell (note: no `/v1` suffix — Claude Code appends it):

```bash
export ANTHROPIC_BASE_URL=https://api.rayline.ai
export ANTHROPIC_API_KEY=rlk-your-key-here
```
