Claude Code is the most common way to use Rayline. There are two paths: **environment variables** (quickest) or the **`rl` CLI** (deeper integration with telemetry, local models, and the menubar app).

## Option 1: Environment variables (fastest)

Set two environment variables before launching Claude Code:

```bash
export ANTHROPIC_BASE_URL=https://api.rayline.ai/v1
export ANTHROPIC_API_KEY=rlk_your_key_here
```

Then start Claude Code normally:

```bash
claude
```

<Tip>
Add the exports to your `~/.zshrc` or `~/.bashrc` to make them persistent across sessions.
</Tip>

### What this does

- Claude Code sends all API requests to `api.rayline.ai` instead of `api.anthropic.com`.
- Rayline authenticates with your `rlk_` key, classifies each request, and routes it to the optimal model.
- Main-agent requests pass through to the frontier model you configured (Opus, Sonnet, etc.).
- Subagent requests — which Claude Code would normally send to Sonnet or Haiku — get routed by Arc-1 to the best-fit model for that task. Often that's an open-source model like DeepSeek or GLM that matches or beats Haiku/Sonnet quality at a fraction of the cost.

## Option 2: The `rl` CLI (recommended)

The CLI wraps Claude Code with pre-configured routing, telemetry hooks, and optional local model support.

### Install

```bash
curl -fsSL https://get.rayline.ai/install.sh | bash
```

### Authenticate

```bash
rl auth login
```

This opens a browser window to `platform.rayline.ai` where you sign in. Your credentials are stored locally at `~/.config/rayline/credentials.json`.

### Launch Claude Code

```bash
rl claude
```

This starts Claude Code with:
- `ANTHROPIC_BASE_URL` pointed at Rayline
- Your Rayline API key injected automatically
- Telemetry hooks installed (per-route cost tracking visible in the dashboard and menubar)
- The local router daemon started if you've configured on-device models

### First-run extras

On macOS (Apple Silicon), `rl claude` automatically installs the **Rayline menubar app** on first launch. The menubar shows live cost savings, recent routes, and router status. See [Menubar Guide](/guides/menubar) for details.

## Verify it's working

After launching Claude Code through either method, give it a task that delegates to subagents:

```
Build a React component with tests and a code review
```

Then check the [Rayline dashboard](https://platform.rayline.ai) — you should see routed requests appearing within a few seconds, with model assignments and cost savings.

## Shell configuration

To make Rayline the default for every Claude Code session, add to your shell profile:

<CodeGroup>
```bash ~/.zshrc
# Rayline routing for Claude Code
export ANTHROPIC_BASE_URL=https://api.rayline.ai/v1
export ANTHROPIC_API_KEY=rlk_your_key_here
```

```bash ~/.bashrc
# Rayline routing for Claude Code
export ANTHROPIC_BASE_URL=https://api.rayline.ai/v1
export ANTHROPIC_API_KEY=rlk_your_key_here
```
</CodeGroup>

Or, if using the CLI, just run `rl claude` instead of `claude` — it handles configuration automatically.

## Disabling Rayline temporarily

To run Claude Code without Rayline routing for a single session:

```bash
ANTHROPIC_BASE_URL= claude
```

Or if using the CLI, just run `claude` directly instead of `rl claude`.
