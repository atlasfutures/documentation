Claude Code is the most common way to use Rayline. The fastest path is the `rayline` CLI: `rayline claude` signs you in, configures routing, and launches Claude Code in one command. On macOS you can do it with one click from the Rayline app. Setting the Anthropic environment variables by hand still works and is covered under [Advanced setup](#advanced-manual-environment-variables).

<Note>
Rayline configures and launches Claude Code — it doesn't bundle it. Install Claude Code first if you haven't: see [Anthropic's setup guide](https://docs.claude.com/en/docs/claude-code/setup).
</Note>

## The easy way: `rayline claude`

Install the CLI:

```bash
curl -fsSL https://get.rayline.ai/install.sh | bash
```

Then launch Claude Code through Rayline:

```bash
rayline claude
```

On a terminal, that single command does everything:

- **Signs you in** — opens the browser to `platform.rayline.ai` the first time and provisions a routing key automatically. You don't need to create or paste a key.
- **Configures routing** — starts a local proxy that forwards Claude Code's traffic to Rayline's router and injects your key. Claude Code keeps talking to its normal Anthropic-compatible endpoint; Rayline classifies each request and routes it.
- **Installs telemetry hooks** — per-route cost and model selection, visible in the dashboard and the Rayline app.
- **Sets up the Rayline app** on first run (macOS Apple Silicon, unless opted out).

Any arguments after `rayline claude` are forwarded to Claude Code:

```bash
rayline claude --resume          # forward a standard Claude Code flag
rayline claude -m opus           # pin the main agent to a specific model
```

## Even easier: the Rayline app

On macOS, `rayline claude` installs the **Rayline app** on first run. From then on you can launch Claude Code without touching the terminal — just click **Launch Claude Code** (⌘↩).

The popover also shows your live savings, lets you pin a model, inspect recent routes, and copy the launch command. See the [Rayline App guide](/guides/menubar) for details.

## Run on-device with `--local`

To route eligible requests to a model running on your own Mac instead of the cloud, add `--local`:

```bash
rayline claude --local
```

This boots Rayline's on-device router and serves inference locally — zero token cost, full privacy. The first run downloads a model (several GB, one-time) and the first response is slow while it loads into memory. After that, eligible tasks route locally and everything else falls back to the cloud router automatically. See [On-Device Routing](/how-it-works/on-device) for what routes locally and the hardware requirements.

## Verify it's working

Give Claude Code a task that delegates to subagents:

```
Build a React component with tests and a code review
```

Then open the [Rayline dashboard](https://platform.rayline.ai) — routed requests appear within a few seconds, with model assignments and savings.

<Tip>
Because `rayline claude` routes through a local proxy, it deliberately does **not** set `ANTHROPIC_BASE_URL` in your shell — so `echo $ANTHROPIC_BASE_URL` is empty even when routing is active. Confirm with the dashboard or `rayline claude --diagnose`, not by inspecting environment variables.
</Tip>

## Advanced: manual environment variables

You can point Claude Code at Rayline without the `rayline` CLI — useful for CI, containers, or non-macOS environments. Set two variables, then run Claude Code normally:

```bash
export ANTHROPIC_BASE_URL=https://api.rayline.ai
export ANTHROPIC_API_KEY=rlk-your-key-here
claude
```

<Warning>
Use `https://api.rayline.ai` with **no** `/v1` suffix — Claude Code appends `/v1/messages` itself. Rayline API keys start with `rlk-` (hyphen). Grab one from the [API Keys page](https://platform.rayline.ai/keys).
</Warning>

To make this persistent, add the exports to your shell profile:

<CodeGroup>
```bash ~/.zshrc
# Rayline routing for Claude Code
export ANTHROPIC_BASE_URL=https://api.rayline.ai
export ANTHROPIC_API_KEY=rlk-your-key-here
```

```bash ~/.bashrc
# Rayline routing for Claude Code
export ANTHROPIC_BASE_URL=https://api.rayline.ai
export ANTHROPIC_API_KEY=rlk-your-key-here
```
</CodeGroup>

## Disabling Rayline temporarily

If you launch with `rayline claude`, just run `claude` directly to skip Rayline for a session. If you set environment variables, unset the base URL for a single run:

```bash
ANTHROPIC_BASE_URL= claude
```
