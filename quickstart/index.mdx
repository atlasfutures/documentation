Rayline works by sitting between your coding agent and the model providers. You point Claude Code at Rayline's endpoint instead of Anthropic's, and Rayline handles the rest — routing each subagent call to the optimal model.

## Prerequisites

1. **A Rayline account** — [Sign up](https://platform.rayline.ai/signup). `rl claude` provisions your routing key automatically; you only need to grab an API key by hand for the [manual env-var setup](/quickstart/claude-code#advanced-manual-environment-variables).
2. **Claude Code** — Rayline currently supports Claude Code. Codex support is coming soon. Rayline configures and launches Claude Code, so install it first if you haven't.

## The quick version

Install the `rl` CLI and launch Claude Code through it:

```bash
curl -fsSL https://get.rayline.ai/install.sh | bash
rl claude
```

`rl claude` signs you in, provisions a routing key, and launches Claude Code with Rayline routing configured — all in one command. On macOS it also sets up the **Rayline menubar app**, so you can launch Claude Code with one click from then on.

Done.

## What happens next

- **Your main agent** continues using whatever model it was configured for (Opus, Sonnet, etc.). Rayline passes main-agent requests through to the frontier model.
- **Subagent calls** — tasks Claude Code delegates to sub-agents like code review, exploration, and frontend work — get classified by Arc-1 and routed to the best model for that specific task. Instead of defaulting to Sonnet or Haiku, they may route to DeepSeek, Kimi, GLM, or other models that deliver equal or better quality at lower cost.
- **You see the savings** in the [Rayline dashboard](https://platform.rayline.ai) — cost breakdown, model distribution, and a counterfactual comparison.

## Prefer to set environment variables yourself?

You can point Claude Code at Rayline without the CLI — useful for CI, containers, or non-macOS setups. See [Advanced: manual environment variables](/quickstart/claude-code#advanced-manual-environment-variables), then browse the [CLI Reference](/cli) for the full command set.
