## Check a routed session

1. Launch a session using the [Claude Code](/tools/claude-code) or [Codex](/tools/codex) instructions.
2. Confirm the environment and account match the activity view.
3. Inspect the selected model and token usage, not only a projected savings total.

Local runtime state is available from `raydock router status`. A running menu bar app does not prove that a particular request used the local model.

See [local routing](/raydock/local-models) before interpreting local activity as an offline or privacy guarantee.
