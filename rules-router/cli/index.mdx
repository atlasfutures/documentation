title: "Rayline CLI"
description: "Install and inspect the supported CLI commands."
---

The current binaries are `rayline` and the `rld` daemon. Install from [Rayline releases](https://github.com/rayline-ai/rayline/releases) using the [OS-specific installer](https://github.com/rayline-ai/rayline#install).

```bash
rayline --version
rayline --help
rayline update --check
```

| Command | Purpose |
| --- | --- |
| `rayline auth login` | Sign in for hosted routing |
| `rayline claude` | Launch Claude Code with hosted routing |
| `rayline claude --local` | Run the on-device hybrid router |
| `rayline codex -- exec "summarize this repo"` | Run Codex through Rayline |
| `rayline codex app` | Launch routed Codex desktop |
| `rayline router status` | Inspect the local router |
| `rayline router logs --lines 120` | Read recent local logs |
| `rayline router stop` | Stop the local router |

For the complete version-specific flags and configuration schema, use `--help` and the [source CLI guide](https://github.com/rayline-ai/rayline/blob/main/docs/getting-started.md). Examples here are aligned to the repository's pinned Rayline source; check your installed version before using advanced options.
