Client launch commands start the runtime for you. To inspect it:

```bash
rayline router status
rayline router logs --lines 120
rayline top
rayline top --json
```

`rayline top` shows live request metrics. `--json` prints one snapshot, and `--all` includes Claude Code's background traffic that the proxy passes through. `rayline router top` is the same command.

Logs can include sensitive request information. Review and redact them before sharing.

## Start a runtime separately

Start the runtime without launching a client when you want to drive it from your own code:

```bash
rayline router start
rayline router start --route subagents
rayline router start --mode codex --auth subscription
```

| Option | Purpose |
| --- | --- |
| `--mode anthropic\|codex` | Choose the inbound API. `anthropic`, the default, serves the transparent proxy on `http://127.0.0.1:20810`. `codex` serves OpenAI Responses on `http://127.0.0.1:20811/v1`. |
| `--route all\|subagents` | Choose what goes through the router. The default is `all`; request model `rayline-local` to reach the on-device model. |
| `--config <path>` | Supply endpoints and routes. Overrides `--route`. |
| `--auth auto\|subscription\|none` | With `--mode codex`, choose the Codex auth source. `--subscription` is short for `--auth subscription`. |

The on-device model comes from your [`rayline local`](/rules-router/guides/local-models) configuration; `rayline router start` fails until you choose one. A client that uses the Anthropic proxy must trust the proxy's certificate. See [Rayline for agents](/rules-router/quickstart/agents) for SDK examples.

Starting a runtime does not reconfigure a client that is already running.

## Logs

Runtime state lives in `~/.rayline/rld`. `rayline router logs` prints the combined log; read the others with `tail -f`.

| Log | Path |
| --- | --- |
| Router, adapter, and injector | `~/.rayline/rld/rl-rld.log` |
| Bundled llama.cpp server | `~/.rayline/rld/llama-server.log` |
| Transparent proxy | `~/.rayline/rld/rl-rld-proxy.log` |
| Proxy for `--isolated` sessions | `~/.rayline/rld/cc/rl-rld-proxy.log` |

The llama.cpp log exists only when Rayline runs the local model for you.

## Stop

```bash
rayline router stop
```

Stop only when sessions using that runtime can be interrupted. Clients still pointing to it will fail until it is restarted or their configuration changes.
