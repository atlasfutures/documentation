## What to look for

- Was the request executed, or did it fail?
- Which model and provider were selected?
- Did the request follow the main-agent pin or a subagent route?
- Which token categories and actual costs are available?

Compare a representative task before and after changing a policy. A cheaper model or a positive savings estimate is not proof that the task completed correctly.

ARC is in private preview. See [usage and billing](/platform/usage) for the distinction between ARC and Agent Gateway usage.
