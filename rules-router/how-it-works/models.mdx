Open [Agent Gateway settings](https://platform.rayline.ai/settings) for the model catalog and current slot defaults. Select a supported model ID for each assignment; do not substitute a display name into API requests.

Model availability, context windows, vision support, and serving providers can change. Check the selected model's requirements before sending large contexts or image content.

[Routing policies](/rules-router/policies) explains compatibility guards and fallbacks. The catalog does not guarantee every model will be available for every request, and it is not ARC's checkpoint model basket.
