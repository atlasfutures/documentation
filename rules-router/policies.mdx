Open **Agent Gateway** settings in the [platform](https://platform.rayline.ai/settings). Choose the Rules strategy for Claude Code traffic when you want explicit slot assignments. Codex Responses traffic remains on rules routing regardless of the Claude Code strategy selector.

These policies can apply to main-agent requests and delegated subagent work. The controls below describe the hosted coding-agent integrations; other clients must supply compatible requests, and local routing uses its own configuration.

## Slots

| Slot | Purpose |
| --- | --- |
| Cheap | Exploration, summarization, and low-risk work |
| Frontier | Primary model when a cheap model is unsuitable |
| Frontier Strong | High-risk work and delegated main-agent work |
| Delegated Subagent | Subagent calls under the delegated policy |
| Haiku Compact | Large-context compaction and summarization |
| Haiku Small | Small asynchronous work such as titles and tool summaries |

Choose from the model catalog shown in the platform. Default assignments can change; a model family's name is not a substitute for its actual supported model ID.

## Main-agent pinning

A main-agent pin applies to non-subagent requests. It does not pin all delegated work. Subagents continue through the selected policy.

For the balanced hosted policy, the main-agent pin is checked before local eligibility and task-based selection. Context and vision compatibility checks can subsequently promote a request to a suitable fallback. A configured preference is not a promise to send an incompatible request to that model.

## A practical configuration

Keep your preferred main model pinned. Assign an efficient model to Cheap and a stronger model to Frontier. Run a representative task that delegates exploration, then inspect the actual selected models and task outcome. Change one assignment at a time.

## Failures and scope

Fallbacks depend on the policy, model configuration, and error path. Some decisions have no fallback. A model outage, context limit, or authentication problem can still fail a request; routing does not guarantee success.

Local CLI policy configuration and hosted platform slots are different configurations. Read the [local model guide](/rules-router/guides/local-models) before assuming a platform change affects an auth-free local session.
