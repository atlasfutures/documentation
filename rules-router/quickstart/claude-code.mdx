## Install Rayline

Use the [install command](/rules-router/cli#install) for your OS. After installation:

```bash
rayline --version
rayline auth login
rayline claude
```

Without `--local`, the CLI uses hosted Rayline routing. Choose **Rules** and your model assignments in the [platform settings](https://platform.rayline.ai/settings).

<span id="run-on-device-with---local" />

## Try local routing

```bash
rayline claude --local
```

This runs the on-device router without a Rayline account. By default it is hybrid: the main agent remains on cloud Claude and read-only subagents such as Explore route locally. Your cloud provider credentials and any cloud inference charges still apply.

`--route all` sends every subagent to your local model, but the main agent still goes to cloud Claude. A fully local session also needs a router config that sends the main agent to the local model; see [fully local sessions](/rules-router/guides/local-models#fully-local-sessions) for that and for hardware and privacy boundaries.

## Manual setup (without the launcher)

To use hosted Agent Gateway without `rayline claude`, set the same environment variables that `rayline claude --via env` sets. Create a key in **API Keys** on the [Rayline platform](https://platform.rayline.ai/keys) and load it into `RAYLINE_KEY` from your secrets manager; see [API keys](/platform/api-keys). Then:

```bash
export ANTHROPIC_BASE_URL=https://api.rayline.ai
export ANTHROPIC_AUTH_TOKEN="$RAYLINE_KEY"
export ANTHROPIC_MODEL=rayline-router
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=180000
unset ANTHROPIC_API_KEY
claude
```

- Do not append `/v1` to the base URL; Claude Code adds its Messages path.
- `ANTHROPIC_AUTH_TOKEN` sends the key as a bearer token. Unset `ANTHROPIC_API_KEY` so an Anthropic key in your environment is not sent instead.
- `CLAUDE_CODE_AUTO_COMPACT_WINDOW` makes Claude Code compact the conversation at 180,000 tokens. From Rayline 0.2.9 the launcher asks the router for this threshold instead: 95% of the context window of the model your rules pin for the main agent.
- Claude Code sends its own session ID with every request, and Agent Gateway uses it as the conversation ID, so you do not need to add a conversation header.
- Keep the key out of source control and out of files that are checked in.

This routes every request, main agent and subagents, through Agent Gateway. The transparent-proxy features of `rayline claude`, such as `--route subagents` and the local router, need the launcher.

Check it with `claude -p "Reply with the word ready."`, then find the request in [Inspect routed requests](/platform/usage).

## Use ARC Sage or Swift

<ArcPreview />

To let ARC choose the model and reasoning effort for every request, request an ARC tier instead of your routing rules. Coding tools default to **ARC Sage**, `arc-sage`; use `arc-swift` for the cheaper, faster Swift tier. See [Swift and Sage](/arc/models).

```bash
rayline claude --via env -m arc-sage --auto-compact-window 180000
```

- `-m arc-sage` sends every request, from the main agent and from subagents, to ARC Sage.
- `--via env` points Claude Code at the hosted router for this session only, and gives Claude Code your router key as `ANTHROPIC_AUTH_TOKEN`. The default proxy mode also works and keeps the key out of Claude Code.
- `--auto-compact-window` sets when Claude Code compacts the conversation. From Rayline 0.2.9 the launcher asks the router for this threshold and fails if the router reports none for the requested model; this option supplies it.

Without the launcher, use the [manual setup](#manual-setup-without-the-launcher) with these values instead:

```bash
export ANTHROPIC_MODEL=arc-sage
export ANTHROPIC_DEFAULT_HAIKU_MODEL=arc-sage
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=180000
```

`ANTHROPIC_DEFAULT_HAIKU_MODEL` sends Claude Code's background requests, such as titles and summaries, to ARC too. Claude Code logs `unrecognized_model` for ARC IDs in debug output and continues. ARC is billed at the [tier's rate card](/arc/pricing), not your Claude subscription.

For Code sessions in the Claude desktop app, see [Claude Desktop](/tools/claude-desktop); Desktop ignores these environment variables.

## Verify the route

Give the agent a small task, then inspect request activity in the platform for hosted sessions or `rayline router logs --lines 120` for local routing. Check the actual model, errors, and task outcome—not just whether the agent produced text.
