`raydock claude-desktop` runs a small local router for Desktop on `http://127.0.0.1:20831` and, on macOS, saves and selects a **Rayline ARC** inference profile before opening Desktop. The profile adds two models to Desktop's model picker, **arc-sage** and **arc-swift**. Your Rayline key stays in the router. Desktop gets a random token that only unlocks this router on your machine; the router refuses requests without it, as well as requests from web pages.

ARC is not a Claude model, and Rayline isn't affiliated with Anthropic. Desktop requires Claude-style model IDs, so the import uses `claude-arc-sage` and `claude-arc-swift` internally; you never type them.

Install or update the [Raydock CLI](/raydock/cli) before starting. Automatic profile selection is available on macOS; use `--manual` for the import workflow.

## Start the router

```bash
raydock auth login
raydock claude-desktop
```

On macOS, the command starts the router, saves your previous Desktop profile and deployment mode, selects **Rayline ARC**, and opens Desktop. If the configuration changes while Desktop is running, the launcher asks it to quit gracefully before restarting it. Open **Code** and choose **arc-sage** or **arc-swift**.

This router is separate from the one `raydock claude` and `raydock codex` use, so both can run at once.

To keep the router running after you log out or restart, install it as a login service:

```bash
raydock claude-desktop install-service
```

Without the service, run `raydock claude-desktop` again after a restart.

## Manual import

Use this workflow when you want to import the configuration yourself or automatic profile selection is unavailable:

```bash
raydock claude-desktop --manual
```

The command starts the router and prints the configuration path, `~/.rayline/claude-desktop/claude-desktop-import.json`. It leaves Desktop’s profile selection to you.

<Steps>
<Step title="Turn on developer mode">
Open Claude Desktop. From the menu bar, choose **Help → Troubleshooting → Enable Developer Mode**.

</Step>
<Step title="Open the third-party inference settings">
Choose **Developer → Configure Third-Party Inference…**.

</Step>
<Step title="Import the Rayline configuration">
Choose **Import configuration** and select `~/.rayline/claude-desktop/claude-desktop-import.json`. Check the imported values:

| Setting | Value |
| --- | --- |
| Provider | Gateway |
| Gateway URL | `http://127.0.0.1:20831` |
| API key | A random token for this router (starts with `rlt-`) |
| Models | **arc-sage** (the default) and **arc-swift** |
| Model discovery | Off |

</Step>
<Step title="Apply and restart">
Click **Apply Changes**, then **Save & Restart**. On the sign-in screen, continue with the configured gateway instead of signing in with Anthropic.
</Step>
<Step title="Use ARC in Code">
Open **Code** and choose **arc-sage** for challenging tasks or **arc-swift** as a fast everyday workhorse. You can switch between them at any time. Send a short task to check the connection.

</Step>
</Steps>

## Check the setup

```bash
raydock claude-desktop status
raydock claude-desktop validate
```

`status` shows whether the router is healthy and how many requests it has served. `validate` compares Desktop's applied configuration with the router and names any setting that differs; it never prints the key. If Desktop reports that it cannot reach the gateway, run `raydock claude-desktop` to start the router.

## Switch back to your subscription

```bash
raydock claude-desktop off
```

If Raydock selected the profile automatically, `off` restores your previous Desktop profile and deployment mode, then stops the router. You may need to sign in again. Your terminal Claude Code login is unchanged.

If you used manual import and there is no saved prior profile, `off` stops the router and prints the manual switch-back steps:

1. In Claude Desktop, open the account menu at the bottom left, which shows **Gateway**, and choose **Sign out**.
2. On the sign-in screen, sign in with your Anthropic account.


Your claude.ai conversations and settings return. The saved gateway profile remains available. Run `raydock claude-desktop` to start the router and select ARC again, or use the manual workflow above.

## Remove it

```bash
raydock claude-desktop uninstall
```

This restores your previous Desktop profile when Raydock saved one, stops the router, removes the login service, and deletes `~/.rayline/claude-desktop`. The saved **Rayline ARC** profile remains in Desktop; remove it in **Developer → Configure Third-Party Inference…** if you no longer want it.

## Subscription and feature availability

Third-party inference mode uses Rayline Platform for Code sessions and switches away from your Claude subscription. Your subscription conversations are preserved; use the switch-back steps above to return to them.

## Limits

- Chat and Cowork are off while Desktop uses the gateway.
- Desktop shows the tier, **arc-sage** or **arc-swift**, not the model ARC chose. To see which model served a request, use [usage](/platform/usage) or `raydock claude-desktop status`.
- Desktop's effort setting and Claude Code's context-window assumptions are those of a Claude model. ARC chooses the model and effort for each request, and Desktop compacts conversations at its default threshold.
- Anthropic does not support routing Claude Desktop to non-Claude models. A Desktop update can change this behavior.

| Command | Purpose |
| --- | --- |
| `raydock claude-desktop` | Start or reuse the router, select the ARC profile, and open Desktop (macOS) |
| `raydock claude-desktop --manual` | Start the router and print the manual import instructions |
| `raydock claude-desktop status` | Router health, request totals, and the Desktop check |
| `raydock claude-desktop validate` | Compare Desktop's applied configuration with the router |
| `raydock claude-desktop stop` | Stop the router |
| `raydock claude-desktop install-service` | Start the router at login (macOS) |
| `raydock claude-desktop uninstall-service` | Remove the login service |
| `raydock claude-desktop off` | Restore the previous profile when saved, then stop the router |
| `raydock claude-desktop uninstall` | Restore the previous profile when saved, then remove the service and router files |
