Rayline connects the agent harness you already use to models. Follow your tool’s guide to use ARC on Rayline Platform or connect through Raydock.

- **ARC** chooses the model and reasoning effort for every request. Use **ARC Sage** (`arc-sage-1.0`) for challenging coding and agent tasks, or **ARC Swift** (`arc-swift-1.0`) as a fast workhorse for everyday tasks. See [Swift and Sage](/arc/models).
- **Raydock** runs on your computer and connects your tools to cloud services and on-device models. See [Rayline Platform and Raydock](/raydock/connections) to choose the connection for your tool.

## Before you start

1. Create a [Rayline API key](/platform/api-keys). Follow your tool’s guide to connect to the Rayline Platform. Install the [Raydock CLI](/raydock/cli#install) if you want to use a launcher or Raydock.
2. Decide where the requests go. [Rayline Platform and Raydock](/raydock/connections) explains which requests leave your machine and how each path is billed.
3. Check the request in [usage](/platform/usage) after your first task: the requested model, the model that served it, and the charge.

## Other agents and apps

Use ARC and Raydock with agent harnesses for coding, research, automation, and other tasks. Before connecting another client, check its request protocol, authentication, model identifiers, and required features against [tool compatibility](/tools/connections) and [API compatibility](/arc/reference/compatibility). A configurable API base URL alone does not guarantee compatibility. To build your own agent, see [custom agents and SDKs](/tools/custom-agents).
