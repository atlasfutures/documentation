Use [Unreal Agent](https://github.com/unreallabsai/unreal-agent) with ARC through Rayline Platform. Choose **ARC Sage** for challenging coding and agent tasks, or **ARC Swift** as a fast workhorse for everyday tasks.

<span id="install" />
<span id="direct-api-availability" />

## Direct API

This setup needs a Rayline environment that [advertises Responses support](/arc/availability#check-protocol-support). Check support before connecting; if your environment does not list `responses`, use [Raydock](#raydock) below.

Install the official runner:

```bash
brew install unreallabsai/tap/unreal-agent
```

The GitHub organisation is `unreallabsai`, spelled with the letter *l*. Check that spelling before pulling any container image or tap for it from elsewhere.

Load your Rayline key into `UNREAL_HARNESS_LLM_API_KEY` from your secrets manager;
see [API keys](/platform/api-keys). Configure the Responses provider, using your
Responses-enabled environment's API origin in place of the production origin
below if needed:

```bash
export UNREAL_HARNESS_LLM_PROVIDER=openai
export UNREAL_HARNESS_LLM_BASE_URL=https://api.rayline.ai/v1
export UNREAL_HARNESS_LLM_MODEL=arc-sage-1.0
```

Run the agent from a project directory:

```bash
unreal-agent-runner -workspace "$PWD" -p 'Read the README and explain how to run this project.'
```

The runner writes JSONL events to stdout. The `openai` provider selects the
Responses wire protocol; it does not mean the request is billed by OpenAI.

## Try another ARC model

To use Swift for an everyday task, select it when starting the runner:

```bash
UNREAL_HARNESS_LLM_MODEL=arc-swift-1.0 unreal-agent-runner \
  -workspace "$PWD" \
  -p 'Read the README and summarize the installation steps.'
```

View the model ARC selected and the request’s cost in [Rayline Usage](/platform/usage).

## Raydock

Use Raydock **0.2.12 or later**. Keep the same OpenAI provider as the direct
setup; only the base URL and key change. The gateway holds your real Rayline key
and the runner gets a placeholder. Start a
[cloud-forwarding gateway](/raydock/connections#configure-a-cloud-forwarding-gateway)
in its own shell, then set these in a **different shell**:

```bash
export UNREAL_HARNESS_LLM_PROVIDER=openai
export UNREAL_HARNESS_LLM_BASE_URL=http://127.0.0.1:23811/v1
export UNREAL_HARNESS_LLM_API_KEY=local-client
export UNREAL_HARNESS_LLM_MODEL=arc-sage-1.0
```

Use your gateway's actual port. The placeholder key is for the gateway
described above; its environment holds the real upstream key. This path
forwards cloud inference; it does not run the inference model or ARC locally.
