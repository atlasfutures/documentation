## Quick diagnostics

Run `rayline status` to get a snapshot of your current state — auth, router, and environment:

```bash
rayline status
```

This shows:
- Whether you're authenticated (and to which environment)
- Router daemon state (running, model, ports)
- Proxy state (if applicable)

## Common issues

<AccordionGroup>
  <Accordion title="Claude Code isn't using Rayline">
    **If you launch with `rayline claude`:** routing goes through a local proxy, so `ANTHROPIC_BASE_URL` is intentionally empty — don't use it to check. Run `rayline claude --diagnose` to print the active routing configuration, and make sure you're starting Claude Code with `rayline claude`, not a bare `claude`.

    **If you set environment variables manually:**
    ```bash
    echo $ANTHROPIC_BASE_URL
    echo $ANTHROPIC_API_KEY
    ```

    - `ANTHROPIC_BASE_URL` should be `https://api.rayline.ai` (no `/v1` suffix)
    - `ANTHROPIC_API_KEY` should start with `rlk-`

    **Check the dashboard:** either way, requests should appear in the [Rayline dashboard](https://platform.rayline.ai) within seconds of running a task.
  </Accordion>

  <Accordion title="'Not logged in' error">
    Run `rayline auth login` to re-authenticate. If you're using env vars instead of the CLI, verify your API key is valid at [platform.rayline.ai/keys](https://platform.rayline.ai/keys).
  </Accordion>

  <Accordion title="Requests are failing / 401 errors">
    - **Expired or invalid key**: Go to [API Keys](https://platform.rayline.ai/keys) and verify your key is active. Create a new one if needed.
    - **Zero balance**: Check your balance in the dashboard. Add funds or enable auto top-up.
    - **Wrong environment**: If using `--env dev`, make sure you authenticated against dev: `rayline auth login --env dev`
  </Accordion>

  <Accordion title="No savings showing in dashboard">
    Savings appear only when subagent calls are routed. If you're doing single-turn work (no delegation), there's nothing to route differently.
    
    Try a task that triggers subagents: *"Build a React component with tests and run a code review."*
    
    Also check the **time range** selector — make sure you're looking at the right period.
  </Accordion>

  <Accordion title="Requests seem slow">
    Rayline adds 10–50ms of routing latency per request. If requests feel significantly slower:
    
    - Check your network to `api.rayline.ai`: `curl -o /dev/null -w '%{time_total}' https://api.rayline.ai/healthz`
    - The selected model may be slower than your usual model — check the activity log to see which model was used
    - If using local models, check `rayline router status` for health issues
  </Accordion>
</AccordionGroup>
